# Сжатие видео для Discord

[English version](./README.md)

Приложение для Windows, которое сжимает видео до выбранного ограничения размера
с помощью FFmpeg.

## Возможности

- Вывод MP4/H.264 и WebM/VP9.
- Пресет 9 МБ и произвольный целевой размер.
- Drag and drop и конвертация через контекстное меню Проводника.
- Работа с видео как с аудиодорожкой, так и без неё.
- Настройка разрешения, FPS, частоты и формата аудио.
- Эффекты изменения скорости, glitch и datamosh.
- Этапы прогресса, скорость кодирования, ETA и отмена.
- Русский и английский интерфейс, системная тёмная тема.
- Подписанные автоматические обновления через NetSparkle.

## Требования

- Windows 10 версии 1809 или новее, x64.
- Visual Studio 2022 или .NET 8 SDK для сборки из исходников.
- Git LFS при клонировании, поскольку `ffmpeg.exe` хранится через LFS.

Релизный установщик является self-contained: пользователю не нужно отдельно
устанавливать .NET или FFmpeg.

## Сборка

```powershell
git lfs install
git clone https://github.com/KickerMix/DiscordVideoCompressor.git
cd DiscordVideoCompressor
dotnet build DiscordVideoCompressor.sln -c Release
dotnet test DiscordVideoCompressor.sln -c Release
```

Сборка установщика:

```powershell
.\installer\Build-Installer.ps1
```

Для этого шага требуется Inno Setup 6.

## Использование

1. Выберите или перетащите файл `.mp4`, `.avi`, `.mkv` или `.webm`.
2. Выберите MP4 или WebM и целевой размер.
3. При необходимости настройте кодирование и эффекты.
4. Запустите конвертацию. Результат появится рядом с исходником с суффиксом
   `_cnvrtd`; существующие файлы не перезаписываются.

Установщик может добавить команду в контекстное меню Проводника. Она использует
пресет MP4 на 9 МБ и после завершения помещает выходной файл в буфер обмена.

## Работа FFmpeg

FFmpeg 8.1 встроен в приложение. При первом использовании он извлекается в
кеш с именем по хешу в `%TEMP%\DiscordVideoCompressor`. Устаревшие копии
удаляются автоматически.

Обновление закреплённой сборки после проверки новой версии:

```powershell
.\scripts\Update-Ffmpeg.ps1
```
